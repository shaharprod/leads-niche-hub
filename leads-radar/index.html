🎁 ערכת תוכן
❓ איך זה עובד
1. הגדרות
⚙️ הגדרות → מפתח Google, המיתוג שלך לדוחות, ואופציונלית מפתח Gemini ו-Webhook.
2. סריקה
בוחרים מרכז ורדיוס, מילת חיפוש או קטגוריה → «התחל סריקה». עומק סריקה = לכמה תת-אזורים מחלקים (יותר עסקים, יותר קריאות API).
3. ביקורת מעמיקה
«🔬 נתח» בכרטיס או «נתח את כל העסקים». כל אתר נבדק בשרת ביקורת ייעודי עם מגבלת זמן — אתר שלא עונה מסומן כשגיאה ולא תוקע את התהליך. אפשר לעצור בכל רגע.
4. ציון הזדמנות
0–100. גבוה = ליד טוב יותר. בכרטיס המלא — כל ליקוי עם פוטנציאל השיפור שלו. האחוזים הם משקלות לתעדוף, לא מדידה של גוגל.
5. דוח ביקורת ממותג
«📄 דוח ביקורת» יוצר דוח בעברית עם הלוגו, הצבע ופרטי הקשר שלך — שמירה כ-PDF (הדפסה → שמור כ-PDF) או הורדה כדף HTML חי שאפשר לשלוח ללקוח או להעלות לאתר.
6. פנייה מותאמת
«✉️ פנייה» בונה הודעת וואטסאפ, מייל, תסריט שיחה והודעה ברשתות — לפי הליקויים הספציפיים. עם מפתח Gemini אפשר לנסח מחדש ב-AI.
⚔️ מתחרים ו📍 דירוג מקומי
בכרטיס המלא: השוואה ל-3 המתחרים החזקים באותה קטגוריה עד 3 ק״מ, ו«בדוק דירוג מקומי» — מפת חום של המקום של העסק בגוגל מפות מ-9 או 25 נקודות סביבו.
🔗 קישור חי, 💰 הצעת מחיר, 🏢 רשם החברות
«קישור חי» מעלה את הדוח לשרת שלך ומראה כמה פעמים ומתי הלקוח פתח אותו. «הצעת מחיר» בונה הצעה לפי הליקויים והחבילות שהגדרת. «רשם החברות» מביא ח.פ., סטטוס ותאריך הקמה.
📲 תור וואטסאפ ו🛰️ מעקב אזורים
«תור וואטסאפ» עובר ליד אחרי ליד עם הודעה מוכנה. «⭐ מעקב שבועי» שומר אזור — כל יום ראשון השרת מזהה עסקים חדשים שנפתחו בו (לשונית 📋 הלידים שלי).
🎁 ערכת תוכן, 🔁 סדרת מעקב, 💰 אותות קנייה
«🎁 ערכת תוכן» — AI כותב לעסק תיאור לגוגל, 3 פוסטים ותשובות לביקורות; מורידים כמתנה או שהיא נכנסת לדוח. «🔁 התחל סדרת מעקב» בחלון הפנייה — 3 הודעות (היום / 3 ימים / שבוע) עם תזכורת ב«📋 הלידים שלי». «💰 אותות קנייה» — פיקסלים ותגי פרסום באתר, קישור לספריות המודעות, ובדיקת רישום באינדקסים.
7. משפך לידים
בכל כרטיס בוחרים שלב (נוצר קשר / פגישה / הצעה / לקוח). הליד נשמר ב«📋 הלידים שלי» עם הערות ותאריך מעקב. Webhook שולח לידים ל-Make / Zapier / n8n.
