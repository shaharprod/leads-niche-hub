1 יצירת פרויקט ב-Google Cloud

  1. פותחים ב-Google Chrome את דף יצירת הפרויקט: console.cloud.google.com/projectcreate
  2. בשדה Project name כותבים: leads-radar
  3. לוחצים על הכפתור הכחול CREATE (למטה משמאל).
  4. ממתינים ~15 שניות עד שההתראה בפינה הימנית העליונה מראה שהפרויקט נוצר, ואז לוחצים SELECT PROJECT כדי לעבור אליו.
חשוב: בכל הדפים הבאים ודא שבראש המסך, ליד הלוגו של Google Cloud, כתוב leads-radar — זה בורר הפרויקט. אם כתוב שם פרויקט אחר, לחץ עליו ובחר את leads-radar.

2 הפעלת חיוב (Billing)

גוגל דורשת כרטיס אשראי מחובר כדי ש-Maps/Places יעבדו בכלל — גם בתוך המכסה החינמית.

  1. פותחים console.cloud.google.com/billing
  2. אם אין חשבון חיוב — Create account, ממלאים פרטים וכרטיס אשראי.
  3. אם יש — נכנסים ל-My Projects, מוצאים את leads-radar, בתפריט שלוש-הנקודות בוחרים Change billing ומצמידים את חשבון החיוב.
עלויות — לא אמרתי לך מספר מדויק כי המחירון של גוגל השתנה ואני לא רוצה להטעות אותך. לפני הסריקה הראשונה תבדוק את המספרים העדכניים כאן: mapsplatform.google.com/pricing. בשלב 5 למטה אני מסביר איך לשים תקרת שימוש קשיחה כך שלא תוכל לחרוג בטעות.

4 יצירת המפתח והגבלתו

  1. פותחים console.cloud.google.com/google/maps-apis/credentials
  2. לוחצים למעלה + CREATE CREDENTIALS → API key.
  3. נפתח חלון עם המפתח (מתחיל ב-AIza...). לוחצים Copy — ושומרים אותו רגע בצד.
  4. לוחצים Edit API key (או על שם המפתח ברשימה) כדי להגביל אותו:
    • בחלק Application restrictions → בוחרים Websites → ADD → מדביקים: https://shaharprod.github.io/* → DONE
    • בחלק API restrictions → בוחרים Restrict key → מסמנים בדיוק את: Maps JavaScript API, Places API (New), Geocoding API, PageSpeed Insights API → OK
  5. לוחצים SAVE למטה. ההגבלה נכנסת לתוקף תוך דקה-חמש.
ההגבלה הזו אומרת שגם אם מישהו יראה את המפתח בקוד הדף — הוא לא יוכל להשתמש בו מאף אתר אחר חוץ מ-shaharprod.github.io. זו ההגנה הנכונה לאפליקציה שרצה בדפדפן.

5 תקרת הוצאה — שלא תופתע בסוף החודש

  1. פותחים מכסות של Places API (New)
  2. מוצאים את השורה של Requests per day, לוחצים על עיפרון העריכה ומגדירים מספר שאתה שלם איתו — למשל 500 ליום. זו תקרה קשיחה: כשנגמרת, הקריאות נחסמות ואין חיוב נוסף.
  3. אותו דבר עבור Geocoding API.
  4. בנוסף, מומלץ להגדיר התראת תקציב: console.cloud.google.com/billing/budgets → CREATE BUDGET → סכום חודשי → התראה במייל ב-50%/90%/100%.
